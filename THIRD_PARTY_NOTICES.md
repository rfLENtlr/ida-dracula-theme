# Third-party notices

## Dracula

The color palette and semantic syntax mapping follow the
[Dracula specification](https://spec.draculatheme.com/). Dracula is maintained
by Zeno Rocha and the Dracula community. This community port is not an official
Dracula project.

## Implementation references

The IDA theme mechanism and property names were researched using Hex-Rays'
documentation and the theme files shipped with a locally installed IDA 9.1.
Architecture and compatibility were compared with the MIT-licensed
[IDA Theme Explorer](https://github.com/kevinmuoz/ida-theme-explorer),
[ida-themr](https://github.com/mahmoudimus/ida-themr), and
[Dracula/IDA](https://github.com/dracula/ida) projects. No code or image assets
from those projects are distributed here.
